# 番茄漫剧 · 起量榜单分析

苹果风格的数据展示页，包含：

- 常青榜（反复上榜的稳定剧目）
- 新剧 / 次新剧榜
- 老剧复投榜（两周前多次上榜、近期未上榜的剧目，附选剧依据）
- 8·29 新剧推荐榜
- 特点统计（画风、集数、题材、上榜次数等分布）

## 文件说明

- `index.html`：页面主体（数据内嵌，双击即可打开）
- `data.json`：页面数据（更新数据后替换此文件即可）
- `榜单数据.xlsx`：同数据的 Excel 版

## 更新方式

更新 `data.json`（或重新生成 `index.html`）后推送到仓库，GitHub Pages 会自动更新。
